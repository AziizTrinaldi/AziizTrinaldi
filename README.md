### Projects

**[Hunter System](https://github.com/AziizTrinaldi/hunter-system)**: my study sessions turned into an RPG.
I kept losing focus, so I made a Pomodoro timer where every session earns XP, gold and gear, and skipping my daily target gets me a penalty. Inspired by *Solo Leveling*. Plain HTML, CSS and JavaScript, no install.

**[Smart Door Lock](https://github.com/AziizTrinaldi/Smart-Door-Lock)**: team project.
ESP32 door lock with a fingerprint sensor and an ultrasonic sensor, plus a web dashboard to see who came in and manage access.

**[SingkawangKu](https://github.com/AziizTrinaldi/SingkawangKu)**: a tourism website for Singkawang.
Introduces the city and its places worth visiting. Built with HTML, CSS and vanilla JavaScript.
